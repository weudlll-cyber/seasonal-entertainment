# Security audits

The official FAQ says: "Three independent teams of auditors have examined the code to ensure that it does exactly what it's intended to do."

## The three audits

The official site links to these reports:

- [Callisto Security Contract Audit](https://github.com/EthereumCommonwealth/Auditing/issues/543)
- [QuillAudits Contract Audit](https://raw.githubusercontent.com/Quillhash/Audit_Reports/master/SeasonalTokens%20Smart%20Contract%20Audit%20Report%20-%20QuillAudits.pdf)
- [Paladin Blockchain Security Audit](https://paladinsec.co/assets/audits/20211110_Paladin_SeasonalTokens_Final_Report.pdf)

What two of the reports say:

- **Callisto Security** reported no issues (0 high, 0 medium, 0 low) and three notes.
- **QuillAudits** audited the code from 12 to 19 August 2021 and lists no open issues: its medium and low findings were closed, and two informational notes were acknowledged.

## Timeline

According to the official roadmap, audits of the token contracts were completed in August 2021, and the farm contract was audited in November 2021. The site also says a bug bounty was offered during public testing, before the tokens launched on Ethereum's main network.

## A note on limits

The official disclaimer says the code "has been carefully audited, however there is no way to fully guarantee that the contracts or any software that interacts with them is completely free of vulnerabilities." An audit lowers risk, but it does not remove it.
