## Piece 4 — guests writing in the chat on other sites: done (commit 8e7c331)

- Built, off by default: "Guests can read on other sites" (on), "Guests can write on other
  sites" (off), and per approved site inherit / on / off on Admin → Embedding (audited).
- A guest's frame names its verified site (X-Embed-Origin); the server applies the site's rule
  and lets the request reach the guest routes only. The guest name lives in a signed guest
  token (X-Embed-Guest, bound to the site, key derived from the session secret) kept in the
  frame's own storage: no third-party cookie. Name rules, limits, sanctions and reporting are
  the chat's own code path.
- Choices I made: the frame shows nothing in the room until its site is verified (so a guest
  never reads before the rules are known); a guest token gives no rights of its own; reading
  off is enforced for the frame's requests (a public room's API stays public as before).
