## NEEDS OWNER'S WORD

- **Content-Security-Policy, `'wasm-unsafe-eval'`** (piece 2): libsodium (your choice) runs as
  WebAssembly, which the strict CSP blocked. `script-src` now also allows compiling
  WebAssembly — nothing else: JavaScript `eval` and inline scripts stay forbidden. Without it no
  password form works. Please confirm.
- **Server-side password rules are gone** (piece 2, by design): the server can no longer see the
  password, so minimum (10 characters) and maximum (72 bytes) length are checked only in the
  browser. Details: docs/AUTH.md, "Server-side checks lost".
- **Pre-login reveals legacy accounts** (piece 2): `legacy: true` comes back for accounts made
  before the change (development data only). The legacy route can be deleted once none remain.
