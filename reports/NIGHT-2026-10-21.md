## PIECE 2 — speed and phone width

### Measured (production build)

Per route, the JavaScript and CSS loaded first (gzip):

| Route                                | Before: JS / CSS | After: JS / CSS |
| ------------------------------------ | ---------------- | --------------- |
| every page (/, games, events, chat…) | 293.3 / 10.6 KB  | 112.7 / 8.3 KB  |
| /info/prices                         | 293.3 / 10.6 KB  | 117.2 / 9.4 KB  |
| /embed/chat                          | 293.3 / 10.6 KB  | 114.8 / 8.5 KB  |

The call page's own chunk (with the call service's client) is 144 KB gzip, the Markdown
renderer's 36 KB, the cryptography chunk 190 KB (already loaded only when needed).

Timings: Playwright, cold loads, median of 5, alternating between the two builds, under a
slow-phone profile (1.6 Mbit/s, 150 ms, CPU 4x slower). Lighthouse is not installed and was
not added. Unthrottled local timings swung by more than the differences on this busy machine.

| Page (390 × 844) | Before: FCP / LCP / CLS / bytes | After: FCP / LCP / CLS / bytes  |
| ---------------- | ------------------------------- | ------------------------------- |
| home             | 4560 / 5596 ms / 0.178 / 733 KB | 2456 / 3936 ms / 0.007 / 480 KB |
| prices           | 3968 / 4268 ms / 0.072 / 603 KB | 2012 / 3404 ms / 0.008 / 385 KB |

| Page (1440 × 900) | Before: FCP / LCP / CLS | After: FCP / LCP / CLS |
| ----------------- | ----------------------- | ---------------------- |
| home              | 4860 / 5812 ms / 0.003  | 2936 / 3188 ms / 0.003 |
| prices            | 4280 / 4452 ms / 0.061  | 2332 / 3876 ms / 0.021 |

Largest images, before → after: `logo.webp` 124 → 47 KB, `emblem.webp` 94 → 52 KB, the
quarters 49/47/40/34 → 33/40/33/28 KB. The largest now are the season marks (`summer.svg` 53
KB, `winter.svg` 47 KB raw; compressed by Caddy in production; generated files, left alone).

### What changed (each kept only with a measured gain)

- **Pages loaded on first use**: call page, prices, info pages, admin area, embedded chat
  (`App.jsx`; `Suspense` in `Layout` and `AdminLayout`).
- **Hashed build files cached a year** (`immutable`), the page and `/brand/` checked each
  visit (`server/src/app.js`).
- **Brand images** at twice their largest shown size (the faint quarters at once): 409 → 254 KB
  in all.
- **Lazy images**: the home boxes' faint images, game pictures, event pictures.
- **No layout shift while data arrives**: the featured game and "Up next" keep their room on
  narrow screens; the coin buttons on the prices page stand empty until the prices arrive.
- **Fonts: not changed.** Preloading the four faces made the first paint later (464 vs 400 ms)
  with no gain in layout shift, so it was taken out again.

### Phone width (390 × 844 and 768 × 1024, light and dark, every page)

- No page wider than the window, nothing cut at the edge.
- Under 44 px, fixed:
  - legal links;
  - "All events";
  - the chat's "…" buttons (36 px) and composer buttons (42 px);
  - the converter's fields (40 px);
  - checkboxes, now targeted by their labels (in admin tables an empty 44 px label);
  - the admin table's role field (19 px);
  - the info pages' ↑/↓ (8 × 24 px);
  - the event links;
  - a tiny uploaded picture's link in the chat.
- Fixed on the way:
  - the home banner's "SEASONAL" was cut on a phone;
  - the season tiles' price ran into the mark circle on a phone (the mark moves up beside the
    name there);
  - events squeezed their text between time and image on a phone (the image goes below).
