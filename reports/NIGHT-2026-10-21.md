### Noticed and left alone

- `/api/prices` still sends `spark` (the last day's prices), which no page shows now. Removing
  it would change the API, so it stays and docs/BOTS.md says so.
- `.home__wash` and `.page-wash` use fixed pixel sizes from the mockup.
- The development data has **no info pages**, so the "info page" screenshot is the Info index.
  There is no delete route for info pages, so no temporary one was made.
- `server/test/botImages.test.js` (untouched by the redesign) failed once in a full verify:
  `vi.waitFor`'s 1-second default ran out while the machine was busy. It passed 3 of 3 when
  run alone. Its waits now allow 10 seconds.
- Prettier does not wrap long Markdown lines. Six PR #11 entries in docs/BACKLOG.md were
  rewrapped by hand after their "not merged yet" became "merged 2026-10-20".
